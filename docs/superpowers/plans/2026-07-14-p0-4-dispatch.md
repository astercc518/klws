# P0-4 冷发投放核心 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 把养熟的 MATURE 号喂进冷发:从筛好的 ON_WHATSAPP 目标里取一批,用 ONLINE 且未超每日上限的 MATURE 号**轮流**发出,按号龄爬坡限额守门,发出后标目标 DISPATCHED、消费该号当日配额。

**Architecture:** 新增 `DispatchService`,把 P0-2(TargetNumber)+ P0-3(WarmupProfile/MATURE + LANE_POLICIES 的 mature 爬坡限额)+ P0-1(Account 的 ONLINE + instanceName + Evolution sendText)编排起来。纯配额计算与编排分离;所有 I/O 注入;时钟注入。不改前几段既有逻辑,只消费其接口。

**Tech Stack:** 同前(TypeScript strict · Vitest · Evolution v2)。无新表(DISPATCHED 是既有 TargetNumber.status 字符串列的新取值)。

## Global Constraints

- 沿用既有约束:Node ≥ 20、TS `strict:true` 无 `any`(测试桩除外)、I/O 注入、时钟注入、纯逻辑不碰 wall-clock、频繁提交。
- 投放只从 **连接态 ONLINE 且 养号 MATURE 且 当日未超 mature 限额** 的号发出。
- mature 每日限额用 P0-3 的 `dailyCap(policy, 'MATURE', matureDays)`,matureDays 由 service 从 `maturedAt` 与时钟算出。
- 每号当日已发数复用 `WarmupProfile.sentToday`/`sentTodayDate`(与 P0-3 养号互聊同一计数器,日切换重置)。
- 轮询(round-robin)分摊到多个号,不把单个号一次打满(防封)。
- 不在本计划做:入站捕获/自动计回复/目标回复引流信号(P0-4b)、P0-2 jid 匹配兜底(P0-4b)。

import { dailyCap, type WarmupPolicy } from '../warmup/warmup-policy.js';
import type { WarmupProfile } from '../domain/warmup-profile.js';

export function matureDaysSince(maturedAt: string | null, nowIso: string): number {
  if (maturedAt === null) return 0;
  const diffMs = Date.parse(nowIso) - Date.parse(maturedAt);
  if (diffMs <= 0) return 0;
  return Math.floor(diffMs / 86_400_000);
}

export function remainingMatureQuota(profile: WarmupProfile, policy: WarmupPolicy, nowIso: string): number {
  if (profile.stage !== 'MATURE') return 0;
  const today = nowIso.slice(0, 10);
  const sentToday = profile.sentTodayDate === today ? profile.sentToday : 0;
  const cap = dailyCap(policy, 'MATURE', matureDaysSince(profile.maturedAt, nowIso));
  return Math.max(0, cap - sentToday);
}
```

import { LANE_POLICIES } from '../warmup/warmup-policy.js';
import { remainingMatureQuota } from './dispatch-quota.js';
import type { WarmupProfile } from '../domain/warmup-profile.js';
import type { TargetNumberRepository } from '../ports/target-number-repository.js';
import type { WarmupProfileRepository } from '../ports/warmup-profile-repository.js';
import type { AccountRepository } from '../ports/account-repository.js';
import type { EvolutionClient } from '../evolution/evolution-client.js';

export type Clock = () => string;

interface Sender {
  instanceName: string;
  profile: WarmupProfile;
  remaining: number;
  sentToday: number;
}

export class DispatchService {
  constructor(
    private deps: {
      targets: TargetNumberRepository;
      profiles: WarmupProfileRepository;
      accounts: AccountRepository;
      evolution: Pick<EvolutionClient, 'sendText'>;
      clock: Clock;
    },
  ) {}

  async dispatchBatch(text: string, batchSize: number): Promise<{ dispatched: number; targetCount: number; senderCount: number }> {
    const targets = await this.deps.targets.listByStatus('ON_WHATSAPP', batchSize);
    if (targets.length === 0) return { dispatched: 0, targetCount: 0, senderCount: 0 };

    const now = this.deps.clock();
    const today = now.slice(0, 10);
    const matureProfiles = await this.deps.profiles.listByStage('MATURE', batchSize);

    const senders: Sender[] = [];
    for (const p of matureProfiles) {
      const account = await this.deps.accounts.findById(p.accountId);
      if (!account || account.state !== 'ONLINE') continue;
      const remaining = remainingMatureQuota(p, LANE_POLICIES[p.lane], now);
      if (remaining <= 0) continue;
      const sentToday = p.sentTodayDate === today ? p.sentToday : 0;
      senders.push({ instanceName: account.instanceName, profile: p, remaining, sentToday });
    }
    if (senders.length === 0) return { dispatched: 0, targetCount: targets.length, senderCount: 0 };

    let dispatched = 0;
    let cursor = 0;
    for (const target of targets) {
      if (target.e164 === null) continue;
      let tries = 0;
      while (tries < senders.length && senders[cursor % senders.length]!.remaining <= 0) {
        cursor += 1;
        tries += 1;
      }
      if (tries >= senders.length) break; // all senders exhausted
      const s = senders[cursor % senders.length]!;
      cursor += 1;

      await this.deps.evolution.sendText({ instanceName: s.instanceName, to: target.e164, text });
      await this.deps.targets.save({ ...target, status: 'DISPATCHED' });
      s.sentToday += 1;
      s.remaining -= 1;
      const updated: WarmupProfile = { ...s.profile, sentToday: s.sentToday, sentTodayDate: today };
      await this.deps.profiles.save(updated);
      s.profile = updated;
      dispatched += 1;
    }
    return { dispatched, targetCount: targets.length, senderCount: senders.length };
  }
}
```
